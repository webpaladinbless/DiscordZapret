>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам, после чего удаляет их и отправляет в карантин. В таком случае детект обычно называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky содержит параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы точно понимаете настройки исключений, предпочтительно добавить исключение; при недостаточной уверенности рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите провайдера, отличного от варианта "Поставщик по умолчанию".
    * В Firefox откройте настройку "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, подойдет `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы: [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/webpaladinbless/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно пропустить.

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл.
    * Чтобы определить рабочую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для добавления стратегии в автозапуск откройте **`service.bat`** -> `Install Service` и выберите нужную стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегий.

  Такой запуск удобен для проверки вариантов обхода. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вашей сети**.

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб.
  - **`Check Status`** - просмотр состояния обхода и служб, включая стратегию в автозапуске и WinDivert.
  - **`Game Filter`** - изменение режима обхода для игр и других служб, работающих с UDP и TCP на портах выше 1023.  
  **После смены режима стратегию нужно запустить заново.**  
  Значение в скобках показывает текущий статус: включено или выключено.
  - **`IPSet Filter`** - настройка обхода сервисов, перечисленных в `ipset-all.txt`.  
  Этот пункт полезен при проверке ресурса, который без zapret открывается, а с ним перестает работать.  
  В скобках отображается состояние:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - проверяется принадлежность IP списку
    - `any` - фильтруется любой IP-адрес
  - **`Auto-Update Check`** - включение или отключение автоматического поиска обновлений.
  - **`Replace active fakes`** - замена текущего используемого фейка на другой файл из каталога `bin`.
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**.</ins>
  - **`Check for Updates`** - ручная проверка наличия новой версии.
  - **`Run Diagnostics`** - поиск распространенных причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения.
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - проверка сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/webpaladinbless/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает телеграм (веб версия)

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Откройте текстовым редактором от имени администратора файл `hosts` в созданной папке.
  - Вставьте скопированные строки в конец `hosts` или замените ими ранее добавленные аналогичные записи.
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Результат не гарантируется. Если веб-версия не заработала, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/webpaladinbless/tg-ws-proxy) или публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вариант, который некоторое время работал, может перестать действовать после его обнаружения.
> В репозитории собрано много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из существующих и измените ее параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте, нет ли ошибок.

- Проверьте, присутствует ли адрес ресурса в доменных или IP-списках.

- Поочередно испытайте другие стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация есть в [#765](https://github.com/webpaladinbless/zapret-discord-youtube/issues/765).

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и другие нужные данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце подтвердите действие клавишей Y.
- Удалите каталог zapret.
- Загрузите свежую версию [со страницы релизов](https://github.com/webpaladinbless/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Щелкните по архиву правой кнопкой мыши и откройте свойства. Если внизу справа есть флажок разблокировки, включите его, нажмите применить и затем ОК.
- Распакуйте архив в новый каталог в корне диска, без пробелов, специальных символов и кириллицы.
- Запускайте разные скрипты `general` и проверяйте доступность ресурсов. Если соединение не работает, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`.

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Используйте инструкцию из https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide.

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноименными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. В командной строке Windows (Win+R, `cmd`) определите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.
- Испытайте остальные стратегии, особенно если раньше доступ работал.
- См. также [#251](https://github.com/webpaladinbless/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включен [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно выяснить, какая стратегия открывает YouTube, и запустить ее.
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord.
- Проверьте работу приложения Discord после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если браузерная версия тоже недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения приведены в [#252](https://github.com/webpaladinbless/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/webpaladinbless/tg-ws-proxy).
- Другой вариант - использовать бесплатные MTProto-прокси из интернета.

### Не работают игры

Игры используют разные схемы подключения, поэтому проверить и исправить каждую из них невозможно.

Начните с универсального варианта:
- через `service.bat` обновите ipset и активируйте `Game Filter`;
- если это не помогло, дополнительно включите режим `ipset any`.

У `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Поэтому не оставляйте этот режим включенным постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/webpaladinbless/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите проблему [здесь](https://github.com/webpaladinbless/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса можно распределить по следующим файлам:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда сеть присутствует в `ipset-all.txt`, но конкретный домен фильтровать не следует;
- **`ipset-all.txt`** - IP-адреса и подсети;
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
